选择安装磁盘

选择要安装合璧OS 的磁盘。该磁盘将被分区并格式化，原有数据全部删除。

✗
未检测到可安装磁盘
请检查虚拟机磁盘控制器（virtio / SATA / NVMe）或物理硬盘数据线与电源连接。
⚠
所选磁盘上已存在分区表与数据，安装开始后这些数据将永久丢失且不可恢复。

分区与文件系统

选择分区方式、根分区文件系统与交换分区大小。

💽
自动分区 — 使用整个磁盘
创建 MBR 分区表：swap + 根分区，传统 BIOS 启动
🚀
自动分区 — UEFI 方案
GPT：ESP(512M) + BIOS 引导(2M) + swap + 根分区，UEFI 与 BIOS 双模启动
推荐
🛠
手动分区
自定义根分区大小（GPT 四分区布局），高级用户
📚
自动分区 + LVM
逻辑卷管理，可在线扩展（安装后配置）
📁
ext4
稳定通用，推荐
🧊
btrfs
支持快照与压缩
⚡
xfs
大文件高性能
建议：内存 ≤ 2GB 时设为 2048MB；大内存机器可适当减小
可用 MB 或百分比；留空 / 100% 表示使用剩余全部空间
