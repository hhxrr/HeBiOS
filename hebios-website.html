Features

一块玉璧，两面生辉

安装与使用，皆如 Windows 般熟悉；底层，却是彻底的开放与自研。

双端

图形化安装器

dialog 字符向导与 HTML 网页安装器双端同源：九步语言 / 磁盘 / 分区 / 用户流程， 网页端可在任意设备的浏览器中完成整机安装。

Web 桌面

纯前端桌面环境：文件管理器、终端、音乐、语音助手、设置中心、应用商店等 13 款应用， 单文件即可分发，双击即用。

设置中心 · 13 大类

完整对标现代设置体验：系统、设备、网络、个性化、账户、时间语言、更新、 隐私、游戏——全量 HeBi 品牌化。

hbpm 包管理

自研混合包管理器：deb / mdn 双格式，18 个随盘离线包， FastAPI 商店后台支持上架、开关源、上传解析与下载统计。

UEFI + BIOS 双引导

GPT 四分区布局：ESP、BIOS-Boot、swap、root；i386-pc 与 x86_64-efi 双链 grub-install，OVMF 实机验证启动链完整。

修复中心

启动参数 hebi.repair=1 进入： 引导重装、密码重置、磁盘探测——系统起不来时的救生艇。

Install

三种方式，皆可装机

从传统光盘到无光驱设备，合璧OS 覆盖全部安装场景。

1

光盘 / U 盘安装

将 ISO 写入光盘或 U 盘（BIOS / UEFI 均可引导），进入图形化安装向导， 九步完成语言、磁盘、分区、用户配置。

dd if=HeBiOS-3.0-amd64.iso of=/dev/sdX bs=4M
2

网页安装器

同一 ISO 启动时内置网页安装服务：局域网内任意设备打开提示的 IP 地址， 即可在浏览器中完成整机安装与实时进度跟踪。

http://<安装机IP>:80
3

Web 桌面单文件

不装系统也能体验：HeBiOS-3.0-Web-Desktop.html 单文件包含全部 13 款应用， 双击即可在现代浏览器中运行。

open HeBiOS-3.0-Web-Desktop.html

在线体验安装向导

与装机 ISO 内置的网页安装器同一套界面：语言 → 许可协议 → 选盘 → 分区 → 用户 → 驱动 → 确认 → 安装 → 完成，九步全程可交互。

演示模式

演示版使用模拟磁盘与模拟进度（约 30 秒跑完），不会写入任何数据；真实环境中从 ISO 启动后，局域网内任意设备打开安装机提示的 IP 地址即可访问同一向导，进度实时同步。
